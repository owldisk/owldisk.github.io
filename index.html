See what's eating your disk

A fast, open-source disk space analyzer for macOS. Scan your drive in seconds and explore storage usage with an interactive sunburst chart.

Download for macOS View on GitHub

Features

⚡

Blazing Fast

Parallel scanning with 64 concurrent goroutines. Scans a full 500 GB disk in seconds.

🎨

Interactive Visualization

Sunburst chart with 3 levels of depth. Click to drill down, click center to go back up.

🔎

Accurate Sizes

Reports the same numbers as macOS Finder and About This Mac, including purgeable space.

🗑

Quick Cleanup

Drag files and folders to the trash zone to free up space without leaving the app.

🔒

Privacy First

Runs entirely on your machine. No data leaves your computer. Fully open source.

🧹

Native Performance

Universal binary for Apple Silicon and Intel. No Electron, no web views — native macOS app.

Built with

Modern tools for a native experience

Go Wails v2 React TypeScript D3.js Tailwind CSS
